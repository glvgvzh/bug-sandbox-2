# Пульс города

Небольшая городская афиша на React и TypeScript. В приложении можно просматривать события, фильтровать подборку, открывать подробности и сохранять интересное.

Проект используется как учебная кодовая база для практики расследования и исправления багов. Задачи оформляются отдельно в Issues и открываются постепенно.

## Стек

- React
- TypeScript
- Vite
- Vitest и Testing Library
- CSS без UI-фреймворка

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run check
npm run build
```

Команда `npm run check` запускает форматирование, ESLint, TypeScript и тесты.

## Структура

```text
src/
  components/  компоненты интерфейса
  data/        демонстрационные данные
  hooks/       состояние и переиспользуемая логика
  services/    имитация внешнего API
  utils/       фильтрация и форматирование
```
